# AI Medical Image Segmentation

## Objective
Transition from the educational, built-from-scratch U-Net implementation to a robust, pre-trained AI segmentation engine to rapidly extract 3D anatomical structures from CT scans.

## What is TotalSegmentator?
TotalSegmentator is an advanced, open-source AI segmentation tool for medical imaging. It uses a robust set of pre-trained models (based on the nnU-Net architecture) capable of automatically segmenting over 117 different anatomical structures from CT scans.

## Why We Are Using It
While the custom U-Net in `src/segmentation` is valuable for learning the fundamentals of deep learning in medical imaging, training an accurate 3D medical AI from scratch requires immense computational resources, large annotated datasets, and significant time. Since this project has a 6-day MVP deadline, leveraging a state-of-the-art pre-trained solution like TotalSegmentator allows us to achieve clinical-grade segmentation quality immediately and focus on the 3D reconstruction and interactive planning aspects.

## Input Format
- **Format:** NIfTI (`.nii` or `.nii.gz`)
- **Content:** 3D CT volume (e.g., `ct_15mm_defaced.nii`)

## Output Format
- **Format:** NIfTI (`.nii.gz`) masks
- **Content:** Binary masks where pixels belonging to a specific organ have a value of 1, and background pixels are 0.

## How It Fits Into Our Project
1. The CT scan is loaded.
2. TotalSegmentator runs on the NIfTI file.
3. The resulting organ masks are saved to an output directory (e.g., `outputs/segmentations/`).
4. These masks will be fed into our Day 2 reconstruction module to create 3D meshes using libraries like PyVista or VTK.

## Anatomical Structures We Can Obtain
TotalSegmentator can extract over 100 structures, including:
- **Organs:** Liver, spleen, kidneys, gallbladder, heart, lungs, brain, etc.
- **Bones:** Vertebrae, ribs, pelvis, skull.
- **Vessels:** Aorta, vena cava, pulmonary arteries.
- **Muscles:** Psoas, gluteus, etc.

## Exact Command/API We Will Use
TotalSegmentator can be invoked via the Command Line Interface (CLI) or the Python API:

**Python API:**
```python
import nibabel as nib
from totalsegmentator.python_api import totalsegmentator

# Run segmentation (fast mode recommended for CPU MVP)
nifti_img = nib.load("datasets/raw/ct/ct_15mm_defaced.nii")
segmentation_img = totalsegmentator(nifti_img, fast=True)
nib.save(segmentation_img, "outputs/segmentations/all_organs.nii.gz")
```

**CLI (Alternative):**
```bash
TotalSegmentator -i datasets/raw/ct/ct_15mm_defaced.nii -o outputs/segmentations -ta fast
```

## CPU vs GPU Considerations
TotalSegmentator is highly optimized for GPUs with CUDA support. However, it *can* run on a CPU. Because running on a CPU can be very slow (taking several minutes to an hour depending on the scan size), we will use the `--fast` (or `fast=True`) option. This uses a lower-resolution model that runs significantly faster, which is perfect for an MVP and development testing.

## How to Verify the Segmentation
1. Open the output masks in a medical image viewer (like ITK-SNAP or 3D Slicer).
2. Alternatively, overlay the masks on the original CT scan using `matplotlib` to visually inspect the alignment.

## Common Errors
- **Memory Errors (OOM):** The CT scan might be too large. Using the `fast=True` parameter helps.
- **Orientation Issues:** The NIfTI affine matrix might be incorrectly read, causing the segmentation to fail or output empty masks. TotalSegmentator automatically resamples, but strict affine matrices help.
- **CPU Slowness:** If it takes too long to run, ensure `fast=True` is enabled.

## Important Limitations
- The `fast` mode trades some accuracy for speed.
- It struggles with severe pathologies or artifacts (e.g., metal implants) that were not present in its training data.
